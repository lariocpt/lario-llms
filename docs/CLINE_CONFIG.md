# Cline retired

Cline CLI and VS Code extension provisioning were retired on 2026-10-05.
Machine-setup renders OpenCode only. Both model hosts had their user npm Cline
package removed. Existing conversation and credential state is preserved; no
renderer writes it. Intel tools remain available in OpenCode and Hermes.

Previous configuration instructions are in [history](history/CLINE_CONFIG-before-2026-10-05.md).
