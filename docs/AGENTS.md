# Local coding clients

OpenCode and Cline settings are managed in machine-setup: shared/agents/ plus machines/<host>/config/. The renderer preserves unrelated provider settings and credentials.

Canonical chat providers are geekom, 7900xt and rtx5080; Geekom is the default. Intel has seven workload tools through lario_intel MCP, including translation, speech and semantic ranking. It has no coding provider. See [the hardware overview](../README.md), [OpenCode validation](OPENCODE.md) and [Intel tools](../intel/README.md).

The retired containerized devbox and former model/provider instructions are archived in history/AGENTS-before-2026-10-05.md.
