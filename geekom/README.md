# Geekom — l-dev-ai

128 GiB Strix Halo unified memory with a measured 105 GiB GTT pool. Native Vulkan/RADV
llama.cpp is spawned by llama-swap's user service on :11434. The Vulkan server was rebuilt
from the existing checkout (commit `16c163d56`, build 11389) to support the Flash model's
`qwen4exp` architecture; the previous executable was stale. Flash loaded and completed a
request with 4 × 245760 context and q8 KV. No container backend is used here.

`./geekom` opens the selector; `./geekom list`, `show`, `budget`, or a profile name are
non-interactive alternatives. `main-model.sh` forwards to it. The selected alias is `geekom`;
`main`, `coder`, `smart`, and existing gateway compatibility aliases remain available.

Only five profiles are registered in [models.json](models.json): smart and smart-128k use
Qwen3.8-27B UD-Q8_K_XL with xhigh reasoning; medium and medium-128k use UD-Q4_K_XL with medium
reasoning. The larger windows use 4 × 245760; the 128k-named profiles use 8 × 122880.
Flash Next uses three local UD-Q3_K_XL shards, 4 × 245760, q8 KV. Each reserves two slots
for coding clients. Keep all weights/download caches under `/mnt/AI_Models` (XFS).

Runtime config remains `llama-cpp/config.yaml`, generated by the shared controller;
`.main-model` is compatibility state. Requests to concrete IDs can swap hardware;
requesting `geekom` returns to the script-selected profile. Do not casually restart this
service while users have active inference: it unloads the resident weights.

`geekom options` lists numbered model/resource pairs. Flash Next additionally
offers experimental `qwen38-flash@flash-128k`: six exact 131072-token slots, with
two coding reservations and four advisory fleet slots. It reuses the same three
shards; no download is needed. `balanced` retains three 245760-token slots and
`capacity` retains four. Choose the labelled option in the menu, or pass
`--experimental` for a direct command. Hardware headroom/context/concurrency
checks are still required before promoting the new six-slot geometry.

## Storage expansion

DMI identifies l-dev-ai as GEEKOM A9 Mega. Manufacturer specifications list two
identical M.2 2280 Key-M NVMe slots, each PCIe 4.0 x4 and supporting up to 4 TB.
On 2026-10-06 Linux detected one 2 TB Crucial P310 (`CT2000P310SSD8`), so the
second slot appears available; an empty slot has not been physically confirmed.
See [GEEKOM specifications](https://help.geekompc.com/hc/en-us/articles/14887570898447-A9-Mega-Specifications)
and [host inventory](../research/geekom-storage-20261006.json).
